# Task log

One log per subject, `logs/<subject>.md`. A session or headless run that works on a subject already listed
here appends a dated entry (`## YYYY-MM-DD · session|headless`) to that log and updates *Last updated*; only
a new subject gets a new file. Each entry says what was asked, what was done, the outcome, and where the
evidence is. Requester-private material is never logged here.
